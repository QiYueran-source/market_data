# 数据库字段约定

**这是项目中，数据库字段的约定，用于规范字段名称和类型。**  
**这个文件非常的重要，无论任何数据源，均需要统一遵守。**

该文件约定：  
- 库   
- 表  
- 字段：名称，类型，默认值，注释

## 库
trade_calendar: 交易日历库，用于存放不同数据源的交易日历数据。


## 表
### trade_calendar库
#### akshare_trade_calendar表  

| 字段名 | 类型 | 默认值 | 注释 |
| ------ | ---- | ------ | ---- |
| calendar_date | datetime | Null  | 日历时间，格式为yyyy-mm-dd，所有日期 |
| is_open | int | 0 | 是否交易日，1：是，0：否 |
